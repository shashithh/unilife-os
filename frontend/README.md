# UniLife OS

UniLife OS is a smart student life companion web application designed to help university students manage academic work, wellbeing, budgeting, and collaboration in one platform.

## Features

- Academic Planner for managing tasks and deadlines
- Wellbeing Hub for mood tracking and support features
- Budget Manager for tracking expenses and budgets
- Group Collaboration tools for team coordination

## Technologies Used

- React
- Vite
- Node.js
- Express
- MongoDB

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`

## Project Purpose

The purpose of UniLife OS is to solve common student problems such as missing deadlines, poor time management, stress, money tracking, and group project difficulties.

## Module Overview

This module was developed as part of the UniLife OS system and includes the main frontend and backend functionalities required for student support and productivity.
